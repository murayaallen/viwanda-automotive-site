# Viwanda Automotive — logo v2

**Workshop** and **Marque**, with the full company name spelled out:
`VIWANDA` over `AUTOMOTIVE LIMITED`, both words in one colour. Never `LTD`.

59 SVG masters, 46 PNG exports, 14 icon files. Every file is generated by
`python tools/build_mark.py` (add `--png` for the exports) - edit the
generator, never the output.

---

## 1. Which mark, where

Two marks need a rule or they are not a system, they are a disagreement.

| | Use it for | Never |
|---|---|---|
| **Workshop** | The primary. Website, app icon, job card, invoice, WhatsApp avatar, overalls, parts labels, stationery. If in doubt, this one. | Nowhere. It is the default. |
| **Marque** | The crest. The gate and fascia, a vehicle wrap, a proposal cover, a brass plaque. | **Below about 64 px.** The spun face and the red hub need room and turn to mud without it. |

They share a silhouette, so they never read as two companies. What differs is
the finish, the hub colour and the width of the name.

---

## 2. Pick the file by ground, not by preference

This is the likeliest way the set gets misused.

| Ground | Emblem file | Gold | Contrast |
|---|---|---|---|
| Black / near-black | `*-emblem.svg` | `#D8A52F` | 8.80:1 |
| White / light | `*-emblem-light.svg` | `#8A6411` | 5.37:1 |
| One colour | `*-emblem-mono-white.svg` / `-mono-ink.svg` | — | — |

A gold tuned for black measures **2.25:1 on white**, which is washed out. That
is why the `-light` files exist.

---

## 3. Pick the file by size

| Size | File | Why |
|---|---|---|
| Above ~96 px | `*-emblem.svg` | Bevel and turned face both read |
| 48–96 px | `*-emblem-flat.svg` | Depth closes up; the flat cut stays crisp |
| 24–48 px | `*-emblem-small.svg` | **A different drawing.** Eight fatter teeth, a wider hub, a heavier V with a flat base. The 12-tooth gear closes into a serrated ring at this size. |
| **16–20 px** | `*-emblem-tiny.svg` | **A third drawing.** Six teeth, a gear reduced to a fat collar, a V that nearly fills the hub. At 16 px there is no room for a ring *and* teeth *and* a counter, so everything goes to the V. |

## 4. The files

### SVG masters

| Pattern | What it is |
|---|---|
| `*-emblem.svg` | Full colour, dark grounds. Pure paths. |
| `*-emblem-light.svg` | Deeper gold ramp, light grounds. |
| `*-emblem-flat.svg` / `-flat-light.svg` | No bevel, no texture. 48–96 px. |
| `*-emblem-small*.svg` | The simplified cut. 24–48 px. |
| `*-emblem-tiny*.svg` | The tiny cut. 16–20 px. |
| `app-icon-tiny.svg` | Square icon built from the tiny cut; fills the frame. |
| `*-emblem-mono.svg` | `currentColor`. **Only works inlined in HTML** — it cannot inherit through an `<img>`. |
| `*-emblem-mono-white.svg` / `-mono-ink.svg` | Explicit colour. Use these in an `<img>`. |
| `*-lockup-{dark,light,mono-white,mono-ink}.svg` | Horizontal: emblem plus name. |
| `*-stacked-{...}.svg` | Stacked, for square formats. |
| `*-wordmark-{...}.svg` | The name alone, both lines one measure. For layouts that set the emblem separately. |
| `app-icon.svg`, `app-icon-maskable.svg` | Square icon on its own ground. The maskable one is inset 20% so a launcher can crop it to a circle without clipping the teeth. |

### PNG exports — `png/`

Transparent background, rendered with the webfont baked in. **These are the
files to hand to anyone who is not opening them in a vector editor**, because
the typeface cannot be substituted in a raster.

Emblems at 1024 / 512 / 256 / 128 / 64. Lockups at 2400 / 1200 / 600.
Stacked at 1600 / 800.

### Icons — `icons/`

`favicon.ico` (16/32/48/64/128/256), `apple-touch-icon.png` (180, opaque —
iOS composites a transparent one onto white), `icon-512.png`, `icon-192.png`,
`icon-maskable-512.png`, `icon-maskable-192.png`, plus 120/64/48/32/16.

Built from the **simplified cut** at 32 px and up, and the **tiny cut** at 16
and 24. `favicon.ico` is a genuine multi-image file — seven frames, each
carrying the drawing appropriate to its size, not one picture resized seven
times. That is the point of the format and almost nobody uses it.

## 5. Finish and production

The full emblem is lit from one source at the top left. The chamfer round the
rim, the slope down into the hub and the four facets of the V each take their
colour from the angle they make to that light; the Workshop face is turned
(concentric) and the Marque face is brushed (radial). Nothing is an offset copy
standing in for depth.

**All lockup and wordmark text is outlined** from `fonts/Archivo.ttf` with the
font's own kerning, and both lines of the name are set to one measure. Any file
can go straight to a plotter, an embroidery machine or a printer's RIP; there
is no typeface to substitute.
